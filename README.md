# 家計簿（Webアプリ版）

iPhone の Safari で開いて「ホーム画面に追加」すると、普通のアプリのように全画面で使える家計簿です。

- **無料・期限なし**：App Store も Mac も不要です。
- **完全オフライン**：最初に1回開いたあとは、通信なしで起動・記録・分析まで動きます。
- **データはiPhoneの中だけ**：記録はiPhone内（IndexedDB）に保存され、外部には一切送信しません。
- **データは空から開始**：最初から入っているのは、標準のジャンルとカテゴリだけです。

## 1. 無料で公開する（GitHub Pages・最初の1回だけ）

アプリのファイルを置いておく場所として、GitHub Pages（無料）を使います。

1. <https://github.com> で無料アカウントを作ります。
2. 右上の「＋」→「New repository」を選び、名前（例：`kakeibo`）を入れて **Public** のまま「Create repository」を押します。
3. 「uploading an existing file」を押し、このフォルダの**中身のファイルすべて**（`index.html`、`app.js`、`styles.css`、`sw.js`、`manifest.webmanifest`、アイコン画像4つ）をまとめてドラッグし、「Commit changes」を押します。
4. リポジトリの「Settings」→ 左の「Pages」を開き、Branch を `main`、フォルダを `/ (root)` にして「Save」を押します。
5. 1〜2分待つと、`https://（ユーザー名）.github.io/kakeibo/` のようなアドレスが表示されます。

> 公開されるのはアプリのプログラムだけです。家計簿のデータはiPhoneの中にだけ保存されるので、他の人から見られることはありません。

## 2. iPhoneのホーム画面に追加する

1. iPhone の **Safari** で、上のアドレスを開きます（Chrome などでは追加できません）。
2. 画面下の「共有」ボタン（□に↑）→「ホーム画面に追加」→「追加」を押します。
3. ホーム画面の「家計簿」アイコンから起動します。以後はこのアイコンから使ってください。

一度起動すれば、機内モードでも動きます。

## 3. 大切なデータを守るために

- ホーム画面からアプリを削除すると、データも消えます。
- ときどき **設定 →「バックアップを保存」** でファイルに保存しておくと安心です（「ファイル」アプリやiCloud Driveに保存できます）。
- 機種変更のときは、新しいiPhoneでアプリを追加してから **設定 →「バックアップから復元」** で戻せます。
- 表計算ソフトで見たいときは **設定 →「データの書き出し（CSV）」** を使います。

## 4. アプリを更新するとき（GitHub）

1. パソコンで GitHub の自分のリポジトリ（例：`kakeibo`）を開きます。
2. 「Add file」→「Upload files」を押します。
3. 新しい版のファイルをドラッグします（同じ名前のファイルは上書きされます）。変更がないファイルは入れなくても大丈夫です。
4. 下の「Commit changes」を押します。
5. 「Actions」タブで「pages build and deployment」が緑のチェックになるまで待ちます（1〜3分）。
6. iPhone で通信できる状態のままアプリを開きます。数秒で新しい版に自動で切り替わります（画面が1回読み込み直されます）。切り替わらないときは、アプリを完全に閉じてからもう一度開いてください。

- 記録データはiPhoneの中に保存されているので、更新しても消えません。
- 自分でファイルを書き換えた場合は、`sw.js` の `VERSION`（例：`kakeibo-v1.3.0`）の数字を必ず上げてください。上げないと、iPhoneが新しい版に気づきません。
- 設定画面の一番下にあるバージョン番号で、更新されたか確認できます。


### アイコンを新しくしたとき
ホーム画面のアイコンは、「ホーム画面に追加」したときの画像のまま変わりません。新しいアイコンにするには追加し直しが必要ですが、**ホーム画面から削除するとデータも消える**ため、次の順番で行ってください。

1. アプリの **設定 →「バックアップを保存」** で、ファイルに保存します（「ファイル」アプリなど）。
2. ホーム画面の家計簿アイコンを長押し →「Appを削除」。
3. Safari でアプリのアドレスを開き、「共有 → ホーム画面に追加」。
4. 新しいアイコンから開き、**設定 →「バックアップから復元」** で1.のファイルを選びます。

## 機能

| 画面 | 主な機能 |
|---|---|
| ホーム | 年（プルダウン）と月（‹ ›）の切り替え、収入と支出の割合（円グラフ・収支）、支出の多いカテゴリ、最近の記録 |
| 記録（中央の＋） | 支出／収入、テンキー、お気に入りのカテゴリ、すべてのカテゴリ（検索・★でお気に入り・追加先のジャンルを選んでカテゴリ追加・ジャンルとカテゴリの名前変更／削除／追加）、日時、メモ、繰り返し（間隔・日／週／月／年・曜日・日付／月末・土日祝なら前後の平日にずらす・過去の分をどこから記録するか〔開始日から／今日から／日付を指定〕・未来の予定の表示〔なし〜1年先〕・回数／日付で終了） |
| 履歴 | 左右にスワイプで一覧⇄カレンダー（端でループしない）。一覧（タイムライン）：表示期間（今週〜期間を指定）、新しい順／古い順。カレンダー：上下スワイプで月を移動、日ごとに上段へ収入（緑）・下段へ支出（赤）の金額、未来の予定は薄い数字、日付をタップで明細。記録をタップで編集・削除 |
| 分析 | 左右にスワイプで 収支→支出→収入→推移 を切り替え（端でループしない）。収支：割合・貯蓄率・先月比・固定費の割合・月末見込み・月別の収支・固定費と変動費／支出・収入：ジャンル別の円グラフ・カテゴリ別の先月比較・曜日別の平均・大きな支出TOP5・月別の収入／推移：収支の推移（月ごと・通算の累計〔年はプルダウン〕）・支出と収支の累計ペース（先月と比較）・貯蓄率の推移 |
| 設定 | 繰り返し入力（一覧・一時停止・編集・削除・追加）、カテゴリの管理（並べ替え・名前変更・削除・お気に入り・ジャンル追加）、CSV書き出し、バックアップの保存・復元、すべての記録の削除 |

※「固定費」は、繰り返し入力で自動作成された支出として集計しています。
※ 祝日（振替休日・国民の休日を含む）はアプリ内で計算しているため、通信なしで判定できます。
※ 未来の予定は表示だけで、集計には含まれません。その日になると自動で本当の記録になります。

## ファイル構成

```
index.html            … 画面の土台
styles.css            … デザイン
app.js                … アプリ本体（保存・繰り返し・集計・グラフ・全画面）
sw.js                 … オフライン対応（アプリ本体を端末に保存）
manifest.webmanifest  … ホーム画面用の名前・アイコン設定
apple-touch-icon.png  … ホーム画面のアイコン（iPhone用）
icon-192.png / icon-512.png / maskable-512.png … アイコン（その他の環境用）
```
